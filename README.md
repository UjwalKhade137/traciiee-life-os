# Traciiee — My Personal Life Operating System

> **Tagline:** My Personal Life Operating System  
> **Version:** 1.2  
> **Platform:** Native / Cross-Platform Mobile First (iOS & Android)

Traciiee is a private, single-user personal analytics and life management app that unifies habits, goals, study, fitness, sleep, mood, digital wellbeing, money, daily routine, and journaling into one cohesive dashboard — powered by a daily **Life Score**, an app-wide **Daily Streak**, gamified **XP & Levels**, and **Free-Tier AI Insights**.

---

## ✨ Features

- 📱 **Zero-Friction Trial Account (Guest Mode):** 1-tap entry without signup forms; seamless in-place upgrade to a permanent account with zero data loss.
- 🔥 **App-Wide Daily Streak:** Single streak counter tracking daily activity across any module, with streak freeze protection (1–2 per month).
- ⭐ **Composite Life Score:** Weighted `/100` daily wellbeing index with 7-day sparkline and multi-axis radar/bar breakdown.
- 🎯 **Goals & Habit Checklist:** Interactive habit checklist, milestone tracking, and AI-estimated completion dates.
- ⚡ **Pomodoro / Focus Timer:** 25m focus & 5m break countdown with audio alerts and productivity XP rewards.
- 🎓 **Student Academic Hub:** Coursework, study hours, assignments, uploaded notes, attendance tracking, and quiz schedule.
- 🎊 **College Events & Celebrations:** Campus festival events, Ganesh Mahotsav, Visarjan procession, and Hackathon RSVPs.
- 🤖 **Free-Tier AI Insights Engine:** Powered by Google Gemini Free Tier / smart on-device heuristics with compact JSON summarization, automatic pause on quota exhaustion, and cached insights.
- 🏆 **Gamification Hub:** Leveling system (Level 14 Focus Master), achievements gallery, and 30-day / 14-day challenge mode.
- 📅 **Life Calendar:** 30-day interactive quality heatmap color-coded by daily Life Score.
- 📊 **Life Wrapped:** Spotify-Wrapped style annual/monthly interactive story recap with exportable summary card.
- 💾 **100% Data Ownership:** 1-click JSON and CSV export of all local database tables.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/tracieee.git

# Navigate to project folder
cd tracieee

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build
```bash
npm run build
npm run preview
```
